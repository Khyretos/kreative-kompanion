# Kreative Kompanion v0.1.0

Your self-hosted, FOSS AI companion. One orchestrator per project, tasks run on your own computers, and local models do the work.

## Downloads

| Platform | Files |
| --- | --- |
| Linux | plain binary (`.tar.gz`), AppImage, `.deb` |
| Windows | setup `.exe`, portable `.exe`, `.msi` |
| macOS | universal `.zip` (Intel and Apple Silicon) |
| Android | `.apk` |

## First start

Every app opens a server picker: type your Kompanion server's address (the suggested one is <https://kompanion.kreative-kompas.com>).

## Good to know

- **Windows:** Not code-signed, so SmartScreen asks once ("More info" > "Run anyway").
- **macOS:** Not notarized, so the first start needs right-click > Open.
- **Linux:** The plain binary needs WebKitGTK 4.1 (`libwebkit2gtk-4.1-0`); the AppImage bundles it.
- Check all downloads against `SHA256SUMS`.
