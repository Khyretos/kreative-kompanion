# STU-R2: a refine step you can repeat, OC sheet face prompt and background (2026-10-09)

Kees (2026-10-08): refine a picture again and again in Kreative Studio: 4K for an artist, change the
colours, swap a head but keep a closed helmet, a chibi version, split a character into parts for an
avatar. The OC sheet lost the moustache in the face pass, and seed 304's purple starry sky should be a choice.

## What changed

- OC sheet: the face fix (node 13) has its own prompt (node 16, param `face_prompt`, falls back to the
  prompt when empty: new `fallback` field on string params) and a `background` choice (white, starry)
  through `{bg}` / `{bg_neg}`. FaceDetailer tiles its VAE (a fresh-load run ran out of VRAM in the face fix).
- Five refine types, `[studio] refine = true` (left out of both type pickers), each with
  `[inputs] source = "10"`: refine-4k, refine-change, refine-repaint (+ `mask = "11"`, + face photo),
  refine-chibi, refine-parts (three transparent PNGs). Generated by `tools/refine/gen.py`.
- `[inputs]`: pictures sent with a run (multipart fields `source`, `mask`), all required, uploaded to
  that ComfyUI before the run like the face photo. `params` (JSON) passes a type's own settings; only
  names the type declares, never prompt/size/seed/rating/negative. /studio/make takes 60 MB now.
- Kreative Studio: a Refine tab (picture from the library or an upload, step cards, a brush to paint
  the area, strength, optional face photo), a Refine button on every finished picture and in the
  lightbox, face details and background for the OC sheet, and the facelift (sticky header with a
  "runs on" pill, one-row tabs, compact type cards, picture-first library cards, lightbox with details).

## Findings (soucouyant RX 9070 XT, Loquendo sheet seed 304 as the source)

| Step | Result | Time |
|---|---|---|
| OC sheet, own face prompt `1boy, male focus, mature male, moustache, ...` | front and left keep the moustache, all four male; without it the sides were androgynous | 115-132 s |
| OC sheet, background starry | purple starry sky like seed 304, white keeps the plain sheet | same |
| 4K, detail pass at denoise 0.2 | moustache gone, eyes grey: dropped | 81 s |
| 4K, model only (1920 -> 4x-AnimeSharp -> 3840) | faithful, crisp | 46 s |
| Recolour at 0.65 / 0.85 + lineart 0.9 | white suit stayed white | 113-121 s |
| Recolour at 1.0 + lineart 0.75 | black suit, poses kept; background follows the prompt | 114 s |
| Repaint (painted head, "closed black dragon helmet with horns") | closed horned helmet, rest untouched | 18 s |
| Chibi (IP-Adapter plus, style transfer 0.6) | same suit, headphones, moustache | 65 s |
| Parts (BiRefNet + face box grown 60 px, crop 3) | cut-out, head, body as RGBA | 3-6 s |

Limits: Parts finds the head by the face detector (a dragon head may not be found; then the head layer
is empty). Chibi and Parts work best on one view (crop a sheet first, or chibi the front view).
