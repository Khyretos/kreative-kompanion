# KG-07: project state summary

## Change

- `server/src/statesum.rs` (+ migration 0128: `projects.state_summary`, `state_summary_at`): a plain-text summary of
  a project built from its task rows only, no model: tasks done of total, per-goal progress, running, needs
  attention (needs_input / failed / refused), in review, `Left:` (first 8 open tasks, then "and N more"), and the
  last merged task with its PR link (from the `forge` task events). Bounded to 2000 bytes, cut at a line end.
- Rewritten after every merge (forge webhook moving a task to done) and every task run that ends done
  (`taskrun::finish`). `summary_of` builds and stores an unwritten one on first read.
- Fed to the planner (plan and re-plan prompts start with it) and to the Overseer: its scan adds the `Left:` and
  `Last merged:` lines per project, and its prompt says to answer "what is left" from the `Left:` line.
- `GET /api/projects/{id}/state` returns `{summary, at}`.
