# KG-06: repo memory

## Change

- `server/src/repomem.rs`: three tools a task worker is offered when the run has a folder: `repo_map`
  (files per folder, two levels, plus CLAUDE.md / CONVENTIONS.md / docs/conventions.md heads), `repo_symbols(query)`
  (definitions whose line contains the query, file:line and signature, at most 25) and `repo_decisions(query)`
  (matching lines of docs/decisions*, DECISIONS.md, docs/lessons-learned.md, at most 15). Each runs as a shell
  step in the folder through the same grant as any shell step; answers are cut to 3000 characters at a line end.
  Queries are single-quoted for sh, one line, at most 80 characters.
- `pcagent::Agent::run` offers them and runs them; the worker prompt says to ask them before reading files.
- Not built: a persistent index. The questions use git itself, so there is nothing to keep fresh or store.

## Tests

`cargo test`: 465 pass (5 new, on a real git fixture): the map is under a tenth of the source bytes and carries
the conventions; symbols find `file:line:signature`; decisions return only matching lines; a hostile query
(`x'; touch pwned; echo '`) stays a search word; wrong calls give no command and long answers are cut. The
fixture tests skip with a message when git is missing.
