# KC-01: prompt caching in the Claude (Anthropic) adapter

## Change

- `server/src/llm.rs`: `request_body()` builds the URL and JSON body of a streamed call (moved out of
  `stream_chat`). For `kind = "anthropic"` it adds the top-level `"cache_control": {"type": "ephemeral"}`
  (plus `"ttl": "1h"` from the provider's `ttl`); the provider's `extra_body` is merged last and can
  override it. The OpenAI-compatible body is unchanged.
- `Chunk::Usage` carries `cache_write` / `cache_read`, parsed from `message_start`
  (`cache_creation_input_tokens`, `cache_read_input_tokens`); the OpenAI parser leaves them `None`.
- `server/migrations/0125_call_cache.sql`: nullable `calls.cache_write`, `calls.cache_read`; the chat call
  record stores them and `GET /api/calls` returns `cacheWrite` / `cacheRead`. `tokens_in` stays the
  uncached input only.
- `ttl` in `[[provider]]` (kompanion.example.toml documents it, default 5 minutes).
- Prices vs base input: 5 min write 1.25x, 1 h write 2x, read 0.1x (0.05x Opus/Sonnet 5.5, 0.025x Fable 5.1);
  prompts under 512 tokens are not cached by Anthropic.
