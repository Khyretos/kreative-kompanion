# KG-11: asset import contract

## Change

- Before: nothing checked an asset before it entered a game project; a misnamed file, a 16-bit PNG, a broken `.glb` or an off-style sprite was found in the engine.
- `server/src/assetcontract.rs`: the contract of an engine profile (`Profile::named("kk-engine")`) and `validate(profile, assets)`; one issue (path, rule, one reason sentence) per broken asset and rule.
  - `name`: lowercase snake_case path segments, no spaces, capitals or `..`. `type`: png, ogg, wav, glb or json.
  - `assetimage.rs`: `png` (real 8-bit RGB/RGBA PNG, no interlacing, 1..4096 px) and `atlas` (`*_atlas.png` needs `*_atlas.json` in the same import; frames `{name,x,y,w,h}` unique and inside the image; any `.json` must parse).
  - `assetaudio.rs`: `audio` (wav 16-bit PCM or ogg Vorbis, 44.1 or 48 kHz, mono or stereo, 20 MB).
  - `assetmodel.rs`: `glb` (glTF 2 header, length, JSON chunk, 100,000 triangles, 32 MB) and `lod` (`name_lodN.glb` chains start at lod0, have no gap and lose triangles at every step).
  - `assetstyle.rs`: `style_check` compares the PNGs of one folder (atlases out, at least 3) with the set's median on brightness (0.25), saturation (0.3) and distinct colours (4x) and flags the outlier with the numbers.
- API (`assetcontract_web.rs`): `POST /api/projects/{id}/asset-check` with `{files:[{path,data(base64)}], engine?}`; the engine is the request's, then the project's KG-10 `engine` setting, then `kk-engine`. Answers `{engine, ok, checked, issues}`; an unknown engine is 400. It stores nothing: the asset commit (M6-12) calls it before it commits and refuses on `ok: false`.

## Tests

`cargo test`: 503 pass (10 new in assetcontract_tests.rs: profile lookup, clean assets, names, types, PNG header and size, atlas metadata, audio, glb budget and LODs, an off-model sprite flagged, consistent and small sets left alone; 1 new request-decoding test).
The test PNG, WAV, OGG and GLB bytes are built in the test file, so no binary fixtures are committed. Clippy: no warnings in the new files.
Fresh install: the binary started with `kompanion.example.toml` on a new DB; the new route is registered and answers 403 without the session header.

## Not done

- A live check as the test user (the endpoint needs a project; covered by unit tests and the start-up check).
- Style check uses colour statistics only; it will not catch a differently drawn character with the same palette.
