# KG-01: task tree (2026-10-11)

Gap 1 of kompanion-gaps.md. Done when: a goal with milestones, tasks and dependencies is stored,
shown and editable.

## What changed

- Migration 0122: `tasks.parent_id` (goal > milestone > task > subtask) and `tasks.kind`
  (`goal`, `milestone`, `task`), table `task_deps(task_id, depends_on)`.
- `server/src/tasktree.rs`: kind rules (a goal has no parent, a milestone sits under a goal, a task under
  anything), parent checks (same user and project, never under itself or a subtask), dependency checks
  (same project, no loops), delete keeps the subtasks by moving them up one level.
- Task API: `POST /api/tasks` and `PATCH /api/tasks/{id}` take `kind`, `parentId` (`""` = top level) and
  `dependsOn`; every task in `GET /api/tasks` carries them. Changes go into the task history.
- Web: a "Plan" section on a project's Tasks pane (only when the project has tree data): one row per
  task with kind badge, state, "D/N done" on parents and "Waits on K" for open dependencies; click opens
  the task, whose details link to its parent, dependencies and subtasks. The task editor has Kind,
  Part of and Depends on.
