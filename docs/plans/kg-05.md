# KG-05: MCP tools inside task runs

## Change

- `server/src/mcp_grants.rs` (+ `migrations/0127_mcp_grants.sql`): grants per user, MCP server and tool
  ("*" = every tool of the server), with an expiry (default 24 h, 1 h to 7 days; asking again renews).
  API: `GET/POST /api/mcp-grants`, `DELETE /api/mcp-grants/{id}`; only a configured `[[mcp]]` server can be granted.
- `pcagent::Agent::run`: for a task run (task_id set) the worker is offered the tools of the granted servers
  (from `mcp::tools_cached`, named `server__tool` like the chat tools), nothing for servers without a grant.
  Every call is checked against the grants again when it is made (a guessed or revoked tool is denied without
  reaching the server) and logged in the computer's access log (`kind` mcp, target `mcp:<server>`, detail the tool).
- Chat tools are unchanged (they need no grant).

## Tests

`cargo test`: 460 pass (5 new, with a stub MCP server): grant matching; nothing offered and the call denied
without a grant; offered and answered under a grant; an expired or other server's grant does not count;
a tool grant offers only that tool and revoking stops the call.
